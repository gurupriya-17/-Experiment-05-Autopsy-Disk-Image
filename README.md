# Experiment 5: Create a Disk Image Using Autopsy

## Aim
To create a disk image using Autopsy for digital forensic analysis.

## Tool Used
- Autopsy

## Procedure
1. Open Autopsy on a supported system.
2. Create a new case by entering the case name and other required details.
3. Add the appropriate data source.
4. Select the disk image or storage source to be examined.
5. Configure the required data source settings.
6. Start the analysis process, if applicable.
7. Verify the case and data source details.
